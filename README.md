## Overview

This repository serves as a structured collection of my practical coursework and self-study notes in Python. It is divided into two main areas:

1. **Core Concepts (`/concepts`):** Annotated reference scripts that explain and demonstrate how specific language features, control flows, and data structures work under the hood.
2. **Practical Exercises (`/exercises`):** Homework assignments, algorithmic challenges, and mini-projects ranging from basic syntax drills to complex problem-solving tasks.
